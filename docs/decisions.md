## Решения агента (ledger)

| Решение | Почему |
|---|---|
| `tokens.css` подключается ссылкой из `design/borodach.com/`, без копии | Один источник правды |
| Шрифты Montserrat + Arimo с Google Fonts | В токенах это фолбэки FactorA и Helvetica; оригиналы проприетарные |
| Отступ панели от края `--spacing-sm` (10px), не 14px из DESIGN.md | Токена на 14px нет, разница незаметна |
| Hover CTA: заливка `--color-primary-container` за `--duration-fast` | У оригинала hover не меняет ничего; для отзывчивости добавлен минимальный отклик из токенов |
| Focus-контур оставлен видимым | Оригинал глушит `outline`; это ломает клавиатурную навигацию |
| Плавающая кнопка и кольцо — CSS, без SVG-значка | Оригинальный бейдж — чужой ассет; делаем круг с текстом |
| ~~Зелёные полосы — `repeating-linear-gradient`, только у карточек мастеров~~ (убрано 25.09.2026) | Заглушки заменены реальными фото, `.stripes` удалён из `layout.css` |
| Из карточки «Запишись онлайн» полосы убраны; карточка чистая | Полосы там заменяли картинку телефона оригинала; после появления фото в hero смотрелись чужеродно (выбор пользователя) |
| ~~Демо-фото с borodach.com в hero и трёх плитках~~ (заменено: фото свои) | Демо-файлы удалены 25.09.2026, сайт работает на фото из папки `фотки` (`assets/interior|anton|nikita|brand`) |
| Литералы размеров компонентов (41px, 1156px, 302×72, 135px, 340px) разрешены | Взяты из DESIGN.md, токенов на них нет |
| Мобильный CTA 165×48 — литерал | Размер со скриншота 360px, токена нет |
| Контакты — отдельный тёмный блок под белой панелью, три карточки | Так устроена нижняя часть оригинала; белая панель остаётся про услуги и мастеров |
| Меню из трёх пунктов: Услуги и цены, Мастера, Контакты | Цены живут внутри блока услуг, отдельный якорь дублировал бы `#services` |
| `links.js` вместо `fab.js` | Подставляет ссылки во все кнопки записи (`data-link`), не только в плавающую |
| Ряд карточек мастеров на мобильном — CSS scroll-snap | Меньше JS |
| Метка `#BOXcutLive` вместо `#BORODACHLIVE` | Хэштег бренда, тот же приём |
| Страницы мастеров собираются скриптом из общего шаблона и словаря цен; скрипт лежит вне проекта | Три страницы делят шапку, контакты и футер; цены в одном месте не разъезжаются |
| Логотип — белая версия на прозрачном фоне, сделана из оригинального JPG (`assets/brand/logo-white.png`) | Тёмный фон сайта; исходный JPG тоже лежит в `assets/brand/logo.jpg` |
| Общий `css/photos.css` для работ и интерьера | Одна сетка 3:4 на оба блока |
| Фото из телефона: чёрные полосы скриншотов срезаны автообрезкой, размер ≤1600px, JPEG q82 | Вес `assets/` ≈3 МБ |
| Город и адрес не указываем: заглушка «ул. Примерная, 1» | Из данных город не следует; ставить наугад нельзя |
| Редизайн 27.09.2026: тема «BOX» — тёплый графит, латунный акцент `#e0a23b`, бумажная панель, углы 2–4px | Сайт был слишком близок к референсу (зелёный, белая панель с радиусом 30px). Выбор пользователя: оставить тёмное, поменять акцент и форму |
| Тема лежит в `css/theme.css` (переопределяет токены после `tokens.css`) и `css/skin.css` (форма блоков, перед `footer.css`) | `design/` остаётся только для чтения, а «только `var(--…)`» сохраняется |
| Шрифты: Oswald 700 (заголовки) + Onest 400/700 (текст); Arimo и Montserrat остаются фолбэками. Заменяет «Montserrat/Arimo» из правила 4 | Уходим от Helvetica-заголовков референса; кириллица есть у обоих |
| Жёсткие смещённые тени у кнопок и карточек мастеров (`skin.css`) | Расширяет правило «тени только у fab»: это приём формы «коробки», цвет только через `color-mix()` |
| Плавающая кнопка — квадрат, hero-фото в рамке со смещённым контуром, разделы панели пронумерованы CSS-счётчиком | Фирменный приём вместо круга, растворения фото и центрированных заголовков |
