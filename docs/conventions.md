# Конвенции кода

## HTML

- `lang="ru"`, `<meta name="viewport">`, свои `title` и `description`.
- Один `h1` (hero). Секции — `h2`, карточки — `h3`. Пропусков уровней нет.
- Семантика: `header`, `nav`, `main`, `section`, `footer`. У каждой секции `id` (якорь) и
  `aria-labelledby`, если у неё есть заголовок.
- Картинки — `alt` осмысленный; декоративные — `alt=""`. Фото-заглушки — `div` с `role="img"`
  и `aria-label`.
- Внешние ссылки: `target="_blank" rel="noopener"`. Телефон — `tel:`, мессенджеры — `https://`.
- Нет inline-стилей и `<style>`.

## CSS

- БЭМ: `.block`, `.block__element`, `.block--modifier`. Префикс — имя блока = имя файла.
- Общие блоки (`.btn`, `.tag`, `.container`) — в `layout.css`. Остальное — по файлам блоков.
- Резиновая модель: `clamp(min, средняя-в-vw, max)`, крайние значения — токены. Медиазапрос
  пишем, только когда меняется раскладка (колонки → стопка, скрытие элемента).
- Breakpoints (max-width): **930 · 840 · 768 · 650 · 400**. Значения медиазапросов — литералы.
- Порядок в блоке: раскладка → размеры → типографика → цвет → состояния → `@media`.
- Состояния: `:hover` только под `@media (hover: hover)`; `:focus-visible` — контур
  `--color-primary` толщиной 1px+`outline-offset`. Оригинал глушит фокус — мы нет (доступность).
- `prefers-reduced-motion: reduce` отключает пульс кнопки, переходы и slide drawer.

## JS

- Файл = IIFE: `(function () { 'use strict'; … })();`.
- Находит элементы через `data-*` (`[data-drawer]`, `[data-drawer-open]`), а не по классам.
- Если элементов нет — `return`. Ошибок в консоли быть не должно.
- Глобально только `window.barber`: `barber.config` (из `config.js`) и хелперы `main.js`.
- Ссылки записи и контакты подставляются из `config.js`; в HTML остаются рабочие `href`-заглушки,
  чтобы без JS кнопки вели куда-то.

## Доступность

- Контраст: белый на `--color-primary` 2,7:1 — допустимо только для крупного жирного текста.
- Drawer: `aria-expanded` на кнопке, `aria-hidden` на панели, Esc закрывает, фокус возвращается.
- Плавающая кнопка: `aria-label="Записаться онлайн"`.
- Порядок Tab повторяет визуальный порядок.
