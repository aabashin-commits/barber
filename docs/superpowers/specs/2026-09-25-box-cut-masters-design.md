## Архитектура

- Три статичных HTML в корне (так пути `css/…`, `assets/…` одинаковы и работает file://).
  Шапка, drawer и футер дублируются в трёх файлах — сборщика нет.
- Новый CSS по блокам (один блок — один файл): `master-page.css` (шапка страницы мастера,
  портрет, прайс), `photos.css` (общая сетка фото 3:4 для работ и интерьера). Существующие
  `masters.css`, `hero.css`, `gallery.css`, `contacts.css`, `topbar.css`, `footer.css` правятся.
- JS на страницах мастеров без нового кода: `main.js`, `config.js`, `links.js`, `drawer.js`.
  `config.js`: новые часы и телефон.
- Меню на страницах мастеров ведёт на якоря главной (`index.html#services`, …).
- Только токены из `design/borodach.com/tokens.css`, никаких новых цветов и размеров.

## Фото

Оригиналы в `фотки/` не трогаем. Скрипт (Python + PIL, в scratchpad) кладёт копии в `assets/`:
ширина до 1600px, JPEG, обрезка чёрных полос у скриншотов телефона, смысловые имена.

```
assets/brand/logo-white.png     белая версия на прозрачном фоне (шапка, футер)
assets/brand/logo.jpg           оригинал
assets/interior/…               6 кадров интерьера, фасад, инструменты
assets/anton/portrait.jpg, with-client.jpg, work-1…7.jpg
assets/nikita/portrait.jpg, at-work.jpg, night.jpg
```

Не публикуем: скриншоты yclients (2), афишу с телефоном, коллаж с сертификатом, селфи в зеркале.
Демо-файлы `assets/hero.jpg`, `assets/gallery-1…3.jpg` удаляются после замены.

## Главная страница

- Топбар и футер: логотип BOX cut вместо текстового названия; `title`/`description`/`alt` на
  BOX cut; метка `#BARBERCLUBLIVE` → `#BOXCUT`.
- Hero: фото интерьера (гексагональный свет, синее кресло) вместо демо-фото.
- Галерея (три плитки): фасад, интерьер, инструменты.
- Мастера: 3 карточки-заглушки заменяются двумя: фото, имя, роль, ссылка «Подробнее»
  на страницу. Зелёные полосы убираем — есть настоящие фото.
- Услуги: реальные позиции с ценами «от».
- Контакты: часы Вт–Вс 11:00–20:00, телефон, фасад в карточке адреса. Адрес — заглушка.

«заменить своим текстом».

## Мобильная версия

Портрет над текстом, прайс в одну колонку, сетка работ 2 колонки на 360, 3 на 768+.
Без горизонтального скролла.
