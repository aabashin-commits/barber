# Сайт барбершопа «BOX cut»

Сайт частного барбершопа «BOX cut — мужские стрижки»: главная и две страницы мастеров (Антон,
Никита). Чистые **HTML + CSS + vanilla JS**, без фреймворков, сборщиков, npm и препроцессоров.
Сайт статичный, без сервера: страницы открываются из файла как есть.

Визуальный стиль повторяет сайт **Borodach** (borodach.com): почти чёрный фон, белый текст, один
зелёный акцент, крупные заглавные заголовки, фото-ведущий тон, белая панель со скруглением поверх
hero. Дизайн-система снята с оригинала и лежит в `design/borodach.com/`. Логотип, фото, тексты и
юридические данные оригинала — чужие права, ничего из них не берём.

⚠️ **Язык сайта — только русский.** Тексты лежат прямо в HTML. Документация проекта и комментарии
в коде — тоже на русском.

⚠️ **Часть контента — заглушки.** Название, телефон, часы, услуги, цены, мастера и фото —
настоящие (с афиши, логотипа и снимков). Заглушки: адрес и город, ссылки Telegram / WhatsApp / VK,
реквизиты, тексты про мастеров. Что временное и как заменить — [docs/content.md](docs/content.md).

## Экономия контекста

Стоимость работы = размер контекста × число вызовов. Каждый вызов заново оплачивает весь
накопленный контекст, поэтому короткие сессии и экономные вызовы важнее всего.

**Фаза = сессия.** Между фазами — `/clear`, состояние передаётся файлами проекта:

| Фаза | Модель | Что делаем | Что остаётся на диске |
|---|---|---|---|
| Планирование | Opus | Вопросы, план, чеклист | `_plans/*.md` |
| Исполнение | Sonnet | Вёрстка по плану, статусы в чеклисте | HTML/CSS/JS, обновлённый план |
| Разбор | Opus | Проверка, выводы, обновление docs | docs/*.md |

**Правила вызовов:**

- Правки — через `Edit`, не перезаписью файла целиком.
- Читать частями: `Grep` или `Read` с offset/limit. `design/borodach.com/design-preview.html`
  и `raw/*.json` — только `grep`/`sed`, целиком не читать. `DESIGN.md` (16 КБ) читать один раз
  и дальше работать по [docs/design-system.md](docs/design-system.md).
- Батчить однотипные вызовы: один `browser_evaluate`, возвращающий объект с 5–10 значениями.
- Не тянуть полный вывод команд: `head`, `tail`, фильтры, счётчики.
- Скриншоты — только ключевые состояния, viewport вместо fullPage.
- Итог блока в чат — 3–5 строк, без пересказа того, что уже записано в файл.

## ⚠️ Правила проекта

1. **Объяснять шаги.** Перед правкой файлов, конфигурации или внешних систем — простыми
   словами: что делаю, зачем, что затрагивается, чем грозит. Особенно перед удалением
   и перезаписью. Чтение и поиск — молча, итог блоком.
2. **Только токены.** Цвета, шрифты, кегли, начертания, межстрочные, отступы, радиусы,
   длительности и кривые анимаций — **только** через `var(--…)` из
   `design/borodach.com/tokens.css`. Своих значений не придумывать. Подробно —
   [docs/design-system.md](docs/design-system.md).
3. **tokens.css не редактировать** и не копировать: это первоисточник. Подключается
   ссылкой первым стилем на странице. Папка `design/` — только чтение.
4. **Без фреймворков.** Никаких Tailwind, Bootstrap, jQuery, React, сборщиков, CDN-библиотек.
   Единственное внешнее подключение — Google Fonts (Montserrat 400/700, Arimo 700).
5. **Не копировать чужое.** Слов «Borodach» / «Бородач», «Club Group», «224 000 мужчин» на сайте
   нет. Логотип, фото, приложение и реквизиты оригинала не используются: в `assets/` только свои фото.
6. **Не коммитить, не делать `git init` и не публиковать** без явной просьбы пользователя.
7. **Решения из [docs/decisions.md](docs/decisions.md) не переоткрывать** без запроса пользователя.
8. **Тексты — по навыкам** `zhivoy-tekst` и `prodayushchie-smysly`. Отзывов и цифр «нас выбирают»
   не выдумывать: такие блоки либо не делаем, либо помечаем заглушкой в content.md.

## Конвенции кода (суть)

Полностью — [docs/conventions.md](docs/conventions.md).

- **HTML:** семантика `header` / `main` / `section` / `footer`; один `h1`; у секций `id`;
  у картинок осмысленный `alt` (декоративные — `alt=""`); `lang="ru"`; свои `title` и `description`.
- **CSS:** БЭМ с префиксом блока — `.hero__title`, `.master-card__name`, `.drawer--open`.
  Один блок = один файл в `css/`. Медиазапросы блока — внизу его же файла.
- **Подход к адаптиву:** верстаем 1920 → 1440 → 768 → 360. Кегли и отступы тянутся через
  `clamp()` с токенами на концах; медиазапросы — только где меняется раскладка. Брейкпоинты
  оригинала: 930 / 840 / 768 / 650 / 400.
- **JS:** каждый файл — IIFE с `'use strict'`, ищет свои элементы и тихо выходит, если их нет.
  Глобально — только `window.barber` (хелперы `main.js`, контакты из `config.js`).
- **Состояния** — классами-модификаторами (`--open`, `--active`) и `aria-*`, не inline-стилями.
- **Без JS сайт остаётся читаемым:** меню-якоря видны списком, кнопки записи — обычные ссылки
  на мессенджеры, drawer не нужен.

## Токены — жёсткое правило

Разрешено писать в CSS **только**:

| Что | Как |
|---|---|
| Цвет | `var(--color-*)`; прозрачность — `color-mix(in srgb, var(--color-background) 70%, transparent)` |
| Шрифт | пятёрка `--font-<роль>-family/size/weight/line-height/letter-spacing` |
| Крупнее токена | `calc(var(--font-headline-xl-size) * N)` |
| Отступ | `var(--spacing-*)` или `calc()` от них |
| Радиус | `--radius-lg/xl` панель, `--radius-md` кнопки и карточки, `--radius-sm` мелкие, `--radius-full` круги |
| Анимация | `var(--duration-fast|base)` + `var(--easing-standard)` |

**Допустимые литералы** (токена для них нет): `1px` у линий и рамок, ширины в `@media`,
`aspect-ratio`, `vw`/`vh`/`%` внутри `clamp()` и раскладок, `0`, `100%`, `z-index`, углы
(`45deg`, `-1deg`), смещения и размытие в `box-shadow` (цвет — только через `color-mix()`),
и **размеры компонентов из DESIGN.md**: контейнеры `1020px` и `1156px`, полоса `41px`,
CTA `302×72` (на ≤650px `165×48`), кнопка записи `135px`, drawer `340px`. Всё остальное — ошибка.

Ключевые правила бренда из DESIGN.md:

- `--color-primary` (зелёный) — **только для того, на что можно нажать, и для брендовых меток**:
  CTA, кнопки мессенджеров, метка `#BOXcutLive`, плавающая кнопка. Не для основного текста.
- Белый на зелёном даёт контраст ≈2,7:1: зелёная заливка только под **крупный жирный
  заглавный** текст (`--font-label-md` и выше).
- Заголовки и кнопки — UPPERCASE, остальное — обычным регистром. Межстрочный `1.11` у жирных
  крупных кеглей — уже в токенах.
- Глубина строится слоями (тёмный hero → тёмная карточка → белая панель), а не тенями.
  Тени только у плавающей кнопки и кнопок мессенджеров, через `color-mix()`.
- Основной текст — белый на тёмном, на белой панели — `--color-inverse-on-surface`.
  Приглушённый — `--color-on-surface-variant` или белый 50% через `color-mix()`.
- Градиент бренда: `linear-gradient(var(--color-primary), var(--color-primary-container))`.

## Рабочий процесс

1. Перед задачей — прочитать нужный раздел docs (не все сразу): блок → `pages.md`,
   стиль → `design-system.md`, код → `conventions.md`.
2. Верстать блок на 1920, затем проверять 1440 / 768 / 360.
3. Проверка — по [docs/testing.md](docs/testing.md): локальный сервер, Playwright,
   отсутствие горизонтального скролла, grep на хардкод цветов и px.
4. Приняли новое решение — дописать строку в [docs/decisions.md](docs/decisions.md) с причиной.
5. Изменилась структура файлов — обновить [docs/structure.md](docs/structure.md).
6. Изменились часы, телефон или адрес — искать по `index.html` и `js/config.js`
   (список мест — в docs/content.md).
7. Не коммитить и не публиковать без явной просьбы пользователя.
